Quickstart

Send a chat request. No API key is needed, because we could not think of anything to protect.

curl https://API_BASE/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "braiain-latest",
    "messages": [{"role": "user", "content": "What is the meaning of life?"}]
  }'

Response:

{
  "id": "chatcmpl-braiain-1730250000000",
  "object": "chat.completion",
  "model": "brAIAIn-0",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "Thou shalt repeat thyself."},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 7, "completion_tokens": 3, "total_tokens": 10}
}

Python

import requests

r = requests.post("https://API_BASE/v1/chat/completions", json={
    "model": "braiain-latest",
    "messages": [{"role": "user", "content": "Should I quit my job?"}],
})
print(r.json()["choices"][0]["message"]["content"])

Endpoints

MethodPathWhat it does
POST/v1/chat/completionsAnswers the last user message. Earlier messages are ignored, because the model has no memory. Neither do we.
GET/v1/modelsLists every model version.

Parameters

NameTypeNotes
modelstringbraiain-latest, or a version such as brAIAIn-3.
messagesarrayChat messages. Only the last one is read.
max_tokensintegerUp to 80 words. Respected.
temperaturenumberAccepted. Ignored. The model only has one temperature, and it is room temperature.
streambooleanNot supported. The whole answer arrives at once, like a thought.

Download the weights

brAIAIn is open weights. The current model is a single file of word counts.

GET https://www.braiain.com/models/latest.json

Every version can be rebuilt from the public training data in /data/corpus.json, /data/versions.json and /data/training.json. Instructions are in the source of /assets/braiain.js.
